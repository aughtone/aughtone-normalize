# Reference

Facts and decisions this project keeps close but does not own: things that were settled elsewhere, or settled once and then deliberately stopped being revisited.

Today that is the **Out of Scope** records — features and normalizers this suite has decided not to build, each with the reasoning that led there. They live here rather than in a closed issue because the reasoning is the durable part: a closed issue answers "what happened to that request", while a record here answers "why the answer is still no", which is the question that comes back.

**Not here:** a decision about how the suite *is* built (that is [Architecture Decision Records](Decisions)), how something currently works (that is [Specifications](Specifications)), or work that is merely unscheduled. "Not now" is a tracker issue, not a rejection.
